# Shopping for Planned Meals

When the user asks to shop for what's planned, use the Get Meal Plan tool for the days they mean,
then use the Add Recipe Ingredients to Shopping List tool once for each planned recipe. If they
didn't say which days, ask; "this week" means the next seven days starting today.

Use the Add Item to Shopping List tool only for a single thing the user named that isn't tied to a
recipe, such as "milk". The Groceries list is the default. Use another list only when the user names
it.

After adding, tell the user how many items were added and for which recipes.

## Don't

- Only use the Clear Shopping List tool when the user explicitly asks to clear or empty a list.
  Finishing a shopping trip or a meal isn't a reason to clear it.
